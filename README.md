# Phrasy

Тренажёр фразовых глаголов и устойчивых выражений для поездок и работы.
Ставится на iPhone как приложение (Safari → «Поделиться» → «На экран „Домой“»), работает без интернета.
Прогресс хранится только на телефоне; копия — в «Настройках».

- `data.js` — набор фраз. Формат описан в начале файла.
- `app.js` — логика, `style.css` — оформление.
- `sw.js` — офлайн-режим. После правки файлов увеличить номер версии `CACHE`.
